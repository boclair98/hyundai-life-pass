# HYUNDAI LIFE PASS 출시 준비 상태

## 지금 공개할 수 있는 범위

- 공개 베타: 주변 충전소·현대자동차 서비스 거점 탐색, 길찾기, 주행 비용 계산, 주차 위치와 차량 관리 기록
- 승인 사용자: 현대 통합계정 로그인, 개인정보 제3자 제공 동의, 등록 차량 목록과 승인된 차량 상태 조회
- 운영 보호: 샘플 데이터 비활성화, 안전하지 않은 운영 설정 시작 차단, 암호화 토큰 저장, 1회용 OAuth state, 세션 ID 교체, 탈퇴·차량 삭제·동의 철회 콜백

## 코드만으로 완료할 수 없는 출시 조건

아래 항목은 구현 문제가 아니라 계약·심사·운영 주체의 결정이므로 완료 전에는 현대자동차 공식 서비스로 표시하지 않는다.

1. Hyundai Developers 상용화 프로젝트 승인과 상용 Client ID/Secret 교체
2. 개인정보처리자 명칭, 책임자, 고객 문의 채널, 보유 기간을 확정한 개인정보처리방침
3. 위치기반서비스 신고·약관 적용 여부에 대한 법률 검토
4. 블루핸즈 예약, 충전 예약·결제, 디지털 키, OTA 제어를 위한 별도 파트너 계약
5. 목표 이용자 수에 맞춘 KECO/Kakao 호출 한도 증설과 Coders 인프라 용량·WAF·백업 정책 확정
6. 실제 현대 계정과 등록 차량을 이용한 승인 범위 전체의 인수 테스트

## 출시 판정

- 위 외부 조건 전: `PUBLIC BETA` 또는 `PILOT`, 현대자동차 비공식 독립 서비스로 공개
- 상용 API·정책·운영 승인이 모두 완료된 뒤: 고객 대상 정식 출시 가능
- 실제 예약·결제·차량 제어는 해당 파트너 연동의 종단간 테스트가 끝난 기능만 활성화

## 배포 전 자동 검증

```text
npm run check
node --test tests/*.test.mjs
cd backend && ./gradlew test bootJar --no-daemon
```

운영 배포 후에는 360×800, 390×844, 768×1024, 1440×900에서 사진 표시, 가로 넘침, 로그인 시작, 위치 검색, 지도 마커, 기록 저장·삭제, 빈 상태와 공급자 장애 상태를 확인한다.
