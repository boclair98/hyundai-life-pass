# HYUNDAI LIFE PASS 제품 고도화 기획

기준일: 2026-09-13
제품 방향: 현대자동차 오너의 하루를 읽고, 다음 행동까지 연결하는 **차량 신뢰 루프**

## 1. 한 문장 제품 정의

LIFE PASS는 현대차에서 동의받은 차량 신호와 사용자가 선택한 생활 데이터를 한 화면에서 읽어, “지금 출발해도 되는지·어디서 충전/점검할지·무엇을 기록할지”를 다음 행동으로 연결하는 오너 플랫폼입니다.

이 서비스의 핵심은 데이터를 많이 보여주는 것이 아니라, 출처가 확인된 데이터만 사용해 오너의 판단 시간을 줄이는 것입니다. 현대차가 연동을 검토할 때도 차량 데이터의 사용 목적, 동의 범위, 최신 시각, 실패 상태를 한눈에 확인할 수 있어야 합니다.

## 2. 현대차가 주목할 차별점

### 차량 신뢰 루프

`현대 신호 수신 → 출발 준비도 계산 → 우선 행동 1개 제안 → 충전/케어/기록 실행 → 다음 상태 확인`의 짧은 흐름을 기본 경험으로 둡니다.

- **신호**: 배터리, 주행 가능 거리, 누적 주행, 충전 상태, 차량 경고, 다음 점검 기준
- **판단**: 안전·에너지·케어 3개 축의 상태와 수신 시각
- **행동**: 안전 점검, 현재 위치 기반 충전소, 블루핸즈, 차량 기록으로 즉시 이동
- **신뢰**: 값이 없으면 추정하지 않고 `아직 확인되지 않음`으로 표시하며 공급자와 마지막 수신 시각을 노출

이는 공식 진단이나 주행 허가를 대신하지 않습니다. 오너가 더 빠르게 확인하고 적절한 공식 채널로 이동하도록 돕는 보조 경험입니다.

## 3. 사용자 경험 구조

### 홈: 오늘의 차량 관제 화면

1. 연결 상태와 마지막 수신 시각
2. 오늘의 우선 행동 1개
3. 출발 준비도(안전·에너지·케어)와 각 근거
4. 충전소·차량 상태·정비소·관리 기록의 네 가지 바로가기
5. 예정 일정과 직접 남긴 비용

### 충전

현재 위치를 버튼을 누른 시점에 새로 확인하고, 실시간 공공 충전기 상태·거리·사용 가능 여부·전화·카카오맵 길찾기를 제공합니다. 충전 예약·결제·충전 시작은 제휴 전까지 완료 가능한 기능처럼 노출하지 않습니다.

### 케어

현대에서 받은 차량 경고와 제공 범위를 구분해 보여주고, 실제 블루핸즈 거점 검색·전화·길찾기로 연결합니다. 타이어 개별 PSI처럼 API가 주지 않는 값은 빈칸이나 예시 숫자로 채우지 않습니다.

### 차량 여권·관리 기록

차량에서 수신한 이벤트와 오너가 직접 남긴 기록을 출처별로 나눕니다. 직접 입력한 기록은 공식 정비 이력·예약·보증 판정이 아니며, 공유 링크에도 동일한 범위를 표시합니다.

## 4. 단계별 고도화 로드맵

### 지금 반영하는 기반 (무제휴 공개 베타)

- 출발 준비도와 데이터 근거를 홈의 핵심 카드로 제공
- 정비 방문 브리프를 만들어 오너가 현재 차량 상태를 상담 전에 복사·공유
- 차량 신호 타임라인으로 최근 30회 수신값을 기기 내에 쌓고 직전 상태와의 변화만 비교
- 차량이 멈춘 순간에는 공식 긴급출동 고객센터로 전화 연결하되, 앱 내 접수로 오인시키지 않음
- 신호가 부족할 때 점수 대신 부족한 항목과 연결/새로고침 행동 표시
- 경고·배터리·점검 임박을 우선순위로 정렬하되 진단으로 표현하지 않음
- 충전·정비 탐색은 비로그인에서도 사용 가능
- 위치 거부, 외부 API 지연, 차량 미연결 상태를 각각 복구 가능한 상태로 처리

신호 타임라인은 서버에 새 개인정보 저장소를 만들지 않고 브라우저의 기기 로컬 저장소만 사용합니다. 현대에서 실제로 받은 값과 수신 시각만 기록하고, 미제공 값은 비교에서 제외합니다. 향후 현대차 공식 이벤트 스트림을 사용할 수 있게 되면 동일한 사용자 경험을 서버 이벤트·감사 로그와 연결하되, 오너 동의와 보존 기간 정책을 먼저 확정합니다.

### 현대차 파일럿에서 검증할 것

- 차량 연결 완료부터 첫 유용한 행동까지 걸리는 시간
- 홈의 제안 행동에서 충전/케어 화면으로 이동해 실제 길찾기까지 완료하는 비율
- 새로고침 뒤 데이터 최신성 및 공급자 오류가 사용자에게 정확히 전달되는지
- 동의 범위와 데이터 삭제/연결 해제 흐름의 이해도
- 동일 오너가 7일 동안 다시 방문해 관리 기록을 남기는 비율

### 제휴·상용 승인 후 확장할 것

| 우선 | 연동 | 필요한 주체 | 오너 가치 |
| --- | --- | --- | --- |
| P1 | 블루핸즈 실시간 슬롯·예약·변경·취소 | 현대차/블루핸즈 운영 API | 제안에서 예약까지 한 흐름 |
| P1 | 충전기 예약·결제·충전 시작 | CPO·결제 사업자 | 충전 탐색에서 이용 완료까지 |
| P1 | 보증·리콜·정비 이력 | 현대차 공식 애프터서비스 | 차량 여권의 공식성 강화 |
| P2 | 푸시·문자 알림 | 현대차 메시징/고객 동의 | 점검·충전 리마인드 |
| P2 | 직원·법인 오너 SSO와 차량 그룹 | 현대차 내부 승인 | 임직원/법인 파일럿 |
| P2 | 중고차 양도용 검증 패키지 | 현대차·인증 중고차 조직 | 신뢰 가능한 차량 인수인계 |

공식 승인이 없는 동안에는 위 기능을 성공한 예약, 결제, 보증 판정, OTA 제어로 가장하지 않습니다. 현재 공개 플랫폼은 탐색·준비·기록·공식 서비스로의 이동을 책임집니다.

## 5. 데이터·보안 원칙

- 모든 차량 수치는 현대 응답의 원본 시각과 함께 표시
- 미제공 값은 `미제공`, 지연 값은 `마지막 확인`으로 구분
- OAuth 토큰과 개인정보는 서버에서만 보관하고 화면·로그·저장소에 노출하지 않음
- 연결 해제·동의 철회·데이터 삭제는 재시도 가능한 상태로 제공
- 공공 충전 데이터와 사용자가 직접 입력한 기록을 차량 공식 데이터와 섞지 않음
- 알림·예약·결제처럼 외부 상태를 바꾸는 작업은 승인된 서버 연동 없이는 활성화하지 않음

## 6. 성공 지표와 출시 게이트

### 사용자 지표

- 첫 방문자의 충전소/정비소 탐색 완료율
- 연결 오너의 30초 내 첫 유용한 행동 완료율
- 출발 준비도 카드에서 후속 행동으로 이어지는 비율
- 데이터 최신 시각을 확인한 뒤 새로고침·연결 관리를 수행하는 비율
- 30일 내 관리 기록 재방문율

### 운영 지표

- 차량·충전·지도 공급자별 성공률과 지연률
- 오래된 데이터가 최신 데이터로 오인된 비율 0%
- 위치 권한 거부 후에도 탐색 가능한 비율 100%
- 모바일 360/390/768px 및 데스크톱 1440px에서 가로 넘침 0건
- 헬스체크, 핵심 API, 로그인 콜백의 배포 후 스모크 통과

## 7. 현재 공개 버전의 정직한 경계

이 저장소는 현대자동차의 공식 서비스나 내부 직원용 시스템이 아닙니다. 현대 Developers 승인 범위에 따라 차량 상태를 읽고, 공공 충전·지도·서비스 거점 데이터를 연결하는 파일럿입니다. 실제 예약·결제·진단·디지털 키·OTA·보증 판정은 각 조직과 파트너의 상용 계약, 보안 심사, 개인정보 동의, 운영 SLA가 완료된 뒤에만 추가할 수 있습니다.

따라서 이번 고도화의 목표는 “없는 권한을 흉내 내는 앱”이 아니라, 현대차가 공식 연동을 붙였을 때도 그대로 확장할 수 있는 오너 경험과 신뢰 경계를 먼저 증명하는 것입니다.

## 8. 수익화로 이어지는 제품 순서

수익화는 기능을 유료로 잠그는 일이 아니라, 오너가 반복해서 쓰는 흐름에서 실제 거래가 일어날 때 선택적으로 연결하는 일입니다. 홈의 `내 차 혜택을 한곳에서`는 당장 결제를 받지 않고, 직접 기록한 지출·현대 공식 혜택·향후 제휴 케어를 서로 다른 출처로 보여주는 기반 화면입니다.

1. **반복 사용을 먼저 만든다** — 차량 신호 확인, 충전·케어 탐색, 관리 기록을 빠르고 정확하게 제공
2. **공식 케어 제휴를 연결한다** — 승인된 정비·세차·충전 파트너의 비교·예약·결제·취소 API가 준비된 뒤 완료 거래에만 계약 수수료 적용
3. **선택형 LIFE PASS+를 검증한다** — 장기 기록, 다차량 관리, 리마인드, 상담 브리프처럼 시간을 절약하는 기능만 구독 후보로 검토
4. **공식 커머스와 법인으로 확장한다** — 현대샵/용품 제휴와 계약 법인의 차량 운영 화면을 개인정보 보호 조건 안에서 별도 운영

안전 경고와 기본 차량 상태는 유료로 막지 않으며, 계약되지 않은 할인·예약·포인트·절감액은 표시하지 않습니다. 모델별 필요한 계약·API·결제·개인정보 심사와 측정 지표는 [`docs/MONETIZATION_PLAN.md`](MONETIZATION_PLAN.md)에서 관리합니다.
