# LIFE PASS 수익화 설계

기준일: 2026-09-14
원칙: **수익화는 목적이고, 신뢰받는 오너 경험이 먼저다.**

LIFE PASS를 처음부터 결제 앱으로 만들지 않는다. 오너가 매일 차량 상태를 확인하고, 충전·정비·기록을 반복해서 쓰는 흐름을 먼저 만든다. 그 흐름에서 실제 비용이 발생하는 순간에만 선택형 유료 기능과 제휴를 연결한다.

## 1. 지금 만들고 있는 가치

오너가 앱을 여는 이유는 할인 배너가 아니라 다음 행동을 빨리 결정하기 위해서다.

- **오늘 판단**: 현대차에서 받은 배터리·주행거리·경고·점검 신호를 출발 준비도와 다음 행동으로 정리
- **바로 실행**: 현재 위치의 충전소·서비스 거점을 찾고, 전화·길찾기·공식 페이지로 이동
- **오래 관리**: 오너가 직접 남긴 정비·충전·주유·보험·세차 기록을 한곳에 보관
- **신뢰 연결**: 실제로 받은 값, 마지막 수신 시각, 공식 채널과 앱의 한계를 분리해서 표시

이 네 가지가 반복 사용을 만든 뒤에야 수익화 접점을 붙인다. 안전 경고, 기본 차량 상태, 긴급 지원 연결을 유료 잠금으로 바꾸지 않는다.

## 2. 수익 모델 우선순위

### P1 · 공식 케어 제휴 수수료

블루핸즈·세차·발렛·충전 CPO 등 공식 승인된 파트너의 슬롯, 가격, 예약, 결제 API가 제공되면 오너 동의 후 한 흐름으로 연결한다. 예약이 실제로 완료된 건에만 계약된 중개 수수료를 적용한다.

- 오너 가치: 비교와 예약에 드는 시간을 줄이고, 방문 기록을 차량 여정에 남김
- 필요한 조건: 현대차/파트너 계약, 실시간 재고·예약 API, 취소·환불·민원 책임 주체, 결제대행 심사
- 화면 원칙: 제휴 여부, 최종 결제 주체, 수수료 포함 여부, 취소 규정을 결제 전 명확히 표시

### P2 · 선택형 LIFE PASS+

기본 안전·상태 기능은 계속 무료로 두고, 오너가 시간을 절약하는 부가 기능만 월 구독으로 제공한다.

- 장기 차량 신호 타임라인과 기기 간 동기화(별도 동의)
- 다차량 관리와 가족 공유 권한
- 점검·보험·소모품의 맞춤 리마인드와 상담용 브리프 보관
- 공식 제휴 케어의 우선 탐색·예약 도우미
- 광고 없는 개인화된 차량 관리 화면

가격과 출시일은 실제 원가·파트너 SLA·고객 인터뷰를 확인한 뒤 정한다. 현재 공개 버전은 구독을 판매하거나 결제 성공을 가장하지 않는다.

### P3 · 공식 쇼핑·용품 제휴

현대샵 또는 승인된 부품·용품 파트너로 이동하는 선택형 링크를 제공한다. 구매가 앱 밖에서 일어나는 동안에는 공식 페이지 이동임을 표시하고, 제휴 계약이 체결된 경우에만 동의 기반 전환 측정을 추가한다.

- 추천 근거는 차종·주행거리·오너가 입력한 기록처럼 사용 목적이 설명 가능한 정보로 제한
- 차량 위치·정밀 주행 경로·민감한 건강/금융 정보를 광고 타깃으로 사용하지 않음
- 제휴 링크와 일반 정보 링크를 시각적으로 구분

### P4 · 법인·플릿 운영 패키지

개인 소비자 데이터를 판매하지 않고, 계약한 법인이 소유한 차량 그룹에 한해 운영 화면을 제공한다. 차량 상태 원문과 개인 위치를 최소화하고, 권한·보존 기간·감사 로그를 계약에 명시한다.

- 차량 가동률·정비 예정·충전 비용처럼 업무 목적이 분명한 지표
- 직원 개인의 이동 경로를 감시하는 기능은 제공하지 않음
- 개인용 LIFE PASS와 법인 관리자의 권한·데이터 영역을 분리

광고는 핵심 모델이 아니다. 향후 지역 파트너 안내가 필요할 때도 `광고/제휴`를 명확히 표시하고 차량 안전 판단을 방해하지 않는 위치에만 둔다.

## 3. 제품 안에서의 순서

현재 홈의 `내 차 혜택을 한곳에서`는 수익화 판매면이 아니라 가치 흐름을 보여주는 자리다.

1. 실제로 입력된 이번 달 지출만 표시한다.
2. 블루멤버스 포인트·현대 공식 정비 페이지로 이동할 수 있다.
3. 아직 계약되지 않은 정비·세차·충전 제휴는 `제휴 준비 중`으로 표시한다.
4. 공식 API와 계약이 준비되면 같은 카드에 비교 → 예약 → 결제 → 이용 완료 → 기록을 단계적으로 연결한다.

이 순서를 지키면 비로그인 방문자도 가치를 먼저 이해하고, 연결 오너는 실제 관리 행동을 반복하며, 파트너는 검증된 이용 의도를 가진 요청만 받을 수 있다.

## 4. 측정할 지표

수익 금액을 임의로 약속하지 않고, 다음 지표를 실제 로그와 정산 자료로 계산한다.

- 활성화: 첫 방문 후 충전·케어·기록 중 하나를 완료한 비율
- 반복 사용: 7일·30일 내 차량 상태 확인 또는 관리 기록 재방문율
- 케어 전환: 제휴 상세 조회 → 실제 예약 완료율, 취소율, 환불 소요 시간
- 구독: 체험 시작률, 유료 전환율, 3개월 유지율, 지원 비용
- 제휴: 파트너별 완료 거래액, 계약된 take rate, 정산 차이, 민원율
- 지속 가능성: 고객획득비용(CAC), 고객생애가치(LTV), 매출총이익, 데이터/API 비용

초기 파일럿에서는 숫자를 키우는 것보다 “공식 정보인지, 오너 입력인지, 제휴 제안인지”를 사용자가 정확히 이해하는지 먼저 검증한다.

## 5. 상용 전환 체크리스트

- 현대차 공식 애프터서비스·충전·커머스 조직의 제휴 승인 및 브랜드 사용 범위
- 파트너별 실시간 슬롯·가격·재고·취소·환불 API와 장애 SLA
- 결제대행(PG), 정기결제, 세금계산서, 환불·분쟁 처리 주체
- 위치·차량·계정 데이터의 수집 목적, 보존 기간, 철회·삭제, 광고 동의 분리
- 제휴 링크·추천의 노출 이유와 수수료/광고 표기
- CS 운영, 장애 공지, 공식 고객센터로의 에스컬레이션
- 개인정보 영향평가, 보안 심사, 접근권한·감사 로그, 침투 테스트

현재 추가로 필요한 키는 없다. P1을 활성화할 때 현대차/파트너가 발급하는 예약·가격·결제·정산 자격과 PG 계약 정보가 필요하며, 그 전에는 앱이 공식 예약·결제 완료로 표시하지 않는다.

## 6. 하지 않을 것

- 가짜 할인, 가짜 포인트, 가짜 예약번호·결제번호를 화면에 만들지 않음
- 안전 경고나 공식 차량 상태를 유료 구독 뒤에 숨기지 않음
- 정밀 위치·주행 경로·차량 식별 정보를 광고주나 제휴사에 판매하지 않음
- 계약되지 않은 파트너를 공식 제휴처럼 보이게 하지 않음
- 데이터가 없을 때 추정한 절감액이나 수익을 보여주지 않음

관련 공식 서비스의 공개 범위는 [MyHyundai](https://www.hyundai.com/kr/ko/digital-customer-support/app/myhyundai/myhyundai-information), [블루멤버스 포인트](https://www.hyundai.com/kr/ko/service-membership/bluemembers/bluemembers-point), [서비스 예약](https://www.hyundai.com/kr/ko/service-membership/service-network/service-reservation-search/service-network-reservation)에서 확인한다. LIFE PASS는 해당 공식 기능을 대체한다고 주장하지 않고, 승인된 연동이 생겼을 때 오너 여정에 안전하게 연결하는 것을 목표로 한다.
