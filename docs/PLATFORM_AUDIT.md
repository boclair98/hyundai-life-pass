# LIFE PASS 플랫폼 구조 감사

기준일: 2026-09-14  
목표: 현대차 오너가 앱을 열자마자 `내 차를 확인하고 → 필요한 행동을 하고 → 결과를 다시 기록하는` 한 흐름을 이해하게 만드는 것

## 1. 비교에서 얻은 원칙

### 현대 마이현대

현대 공식 플랫폼은 블루링크, 차량 상태·원격 제어, 카라이프, 블루멤버스, 드라이빙 인사이트, 주변 검색, 차량 서비스, 맞춤 피드, 현대샵, EV 충전을 하나의 계정 경험으로 묶습니다. LIFE PASS도 메뉴를 기능 이름의 모음이 아니라 `차량 신뢰 → 오늘의 행동 → 공식 서비스 연결`의 순서로 보여줘야 합니다.

### 쏘카

쏘카는 예약·지역·시간처럼 사용자가 결정해야 하는 핵심 입력을 첫 화면에 두고, 이용 가능한 지역과 서비스 혜택을 즉시 다음 행동으로 연결합니다. LIFE PASS에서는 이를 `현재 위치 → 충전/정비 → 전화·길찾기` 흐름으로 적용합니다.

### 한화에어로스페이스

한화에어로스페이스 모바일 사이트는 사업 영역을 큰 장면과 단계형 내비게이션으로 나눠, 사용자가 한 화면에서 다음 영역으로 이동하는 감각을 줍니다. LIFE PASS의 장면 전환은 장식이 아니라 `내 차·충전·케어·기록` 영역을 기억하게 하는 공간 표지로 사용합니다.

### 넥토리얼

넥토리얼은 짧은 메시지, 단계가 보이는 진행감, 화면 전환을 결합해 긴 페이지도 하나의 이야기처럼 느끼게 합니다. LIFE PASS에서는 숫자와 카드를 늘리는 대신 현재 상태, 추천 행동, 확인 결과를 순서대로 노출합니다.

## 2. LIFE PASS의 큰 틀

| 레이어 | 오너가 보는 질문 | 현재 책임지는 화면 |
| --- | --- | --- |
| 정체성 | 어떤 차를 보고 있나? | 현대 계정 연결, 선택 차량, 마지막 수신 |
| 오늘의 판단 | 지금 출발해도 되나? | 오늘의 차량 브리핑, 출발 준비도 |
| 행동 | 무엇을 하면 되나? | 현재 위치 충전소, 블루핸즈, 주행 도구 |
| 신뢰 기록 | 무엇이 언제 바뀌었나? | 차량 신호 타임라인, 차량 여권, 오너 기록 |
| 공식 연결 | 문제가 생기면 어디로 가나? | 정비 방문 브리프, 공식 긴급출동 전화 |

모든 화면은 이 다섯 레이어 중 하나의 질문에 답해야 하며, 같은 데이터를 다른 카드로 반복하지 않습니다. 값이 없으면 다음 행동을 추정하지 않고 `연결·새로고침·공식 채널` 중 하나만 제안합니다.

## 3. 이번 고도화에 반영한 것

- 차량 신호를 시간순으로 쌓는 기기 로컬 타임라인
- 직전 수신 대비 배터리·주행 가능 거리·누적 주행·경고 변화만 표시
- 정비소 상담용 브리프와 공식 긴급출동 전화의 명확한 경계
- 모바일에서 카드를 한 열로 재배치하고 모든 주요 행동을 44px 이상 터치 영역으로 유지
- 위치 기반 기능은 요청 시점의 GPS를 사용하고, 위치 거부 시에도 기본 탐색을 계속 제공

## 4. 다음 공식 연동 게이트

아래 기능은 화면을 먼저 만들지 않고, 현대차·블루핸즈·충전사업자와 승인된 API·동의·운영 SLA가 확보될 때만 활성화합니다.

1. 블루핸즈 실시간 예약·변경·취소와 정비 이력
2. 충전 예약·결제·충전 시작 및 영수증
3. 블루링크 원격 제어·목적지 전송·주차 위치
4. 드라이빙 인사이트용 주행 이벤트 스트림과 푸시 알림
5. 블루멤버스 포인트·혜택과 차량별 맞춤 피드

그 전까지 LIFE PASS는 수신 데이터의 출처와 한계를 보여주고, 전화·지도·공식 웹으로 이어지는 준비 플랫폼으로 동작합니다.
