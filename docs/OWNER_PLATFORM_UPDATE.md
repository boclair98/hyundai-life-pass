# 내 차 중심 플랫폼 개편

홈에서 차량 상태, 여섯 가지 바로가기, 예정 일정, 월별 차량 지출을 확인합니다. 소개용 장면 반복을 제거하고 모바일 첫 화면에 기능 진입점을 배치했습니다.

- 충전: 지도, 실제 충전기 상태, 가까운 목록, 검색·필터·즐겨찾기와 길찾기. 요금은 운영사에서 확인하며 거리는 직선거리입니다.
- 정비·점검: 차량 상태와 가까운 블루핸즈를 탭으로 전환합니다. 바퀴별 공기압이 없으면 미제공으로 표시합니다.
- 드라이브: 주행·비용 계산, 출발 체크, 주차 위치 탭을 제공합니다. 계산 결과는 운행 가능성을 보장하지 않으며 입력 기준의 예상값입니다.
- 관리 기록: 현대 계정에 연결한 내 차량의 정비·충전·주유·보험·세차·주차 기록을 서버에 저장합니다. 예정 일정, 완료 처리, 월별 비용 합계, 검색, 보관·복원, CSV 내려받기를 제공합니다.

관리 기록은 사용자가 직접 작성한 기록이며 공식 정비 이력이나 정비소 예약이 아닙니다. 일정은 앱 안에서 확인하며 푸시 알림은 제공하지 않습니다. 차량에서 수신한 기록은 별도 탭에서 확인합니다. 내 계정과 차량 소유권을 매 요청마다 확인하고, 차량 삭제 시 관련 관리 기록도 삭제됩니다.

홈·기능 화면의 빈 데이터는 실제 차량 상태처럼 채우지 않습니다. 현대자동차 공식 서비스와 별개로 운영하는 서비스입니다.

배포에는 기존 계정·외부 연결 설정을 그대로 사용하며 새로운 발급 키가 필요하지 않습니다. 새 저장 테이블은 Flyway V8에서 생성합니다.
