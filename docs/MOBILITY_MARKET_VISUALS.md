# 모빌리티 서비스 마켓 비주얼

홈의 충전·차량 케어·차량 기록을 서로 다른 장면으로 구분하기 위해 내장 이미지 생성 도구(`image_gen`)로 제작한 콘셉트 이미지입니다. 현대자동차의 공식 촬영물이나 실제 시설 사진이 아니며, 특정 양산차·상표·서비스 성능을 그대로 재현하거나 보증하지 않습니다.

## 저장 파일

- `public/mobility/mobility-hero-v1-{800,1536}.webp`
- `public/mobility/mobility-charge-v1-{800,1536}.webp`
- `public/mobility/mobility-care-v1-{800,1536}.webp`
- `public/mobility/mobility-passport-v1-{800,1536}.webp`

각 장면은 800px과 1536px 두 전달용 WebP로 저장하며 브라우저가 화면 폭에 맞는 파일을 선택합니다. 원본 생성 PNG는 저장소 밖의 Codex 생성 이미지 폴더에 보존했습니다.

## 최종 프롬프트 세트

### 도시 모빌리티 히어로

프리미엄 오리지널 실버·블루 전기 크로스오버가 서울을 연상시키는 미래형 스마트시티 대로를 달리는 블루아워 자동차 캠페인 장면. 왼쪽은 제목을 위한 딥 네이비 여백, 오른쪽에는 차량과 은은한 시안 라이트 트레일. 사람·텍스트·로고·워터마크·기존 양산차 복제 없음.

### 도심 급속 충전

오리지널 다크 블루 전기차가 고급 도심 급속 충전 라운지에서 실제 케이블로 충전 중인 장면. 따뜻한 실내와 차가운 도시 조명을 함께 사용하고 차량·충전기를 명확히 구분. 사람·텍스트·로고·워터마크 없음.

### 정밀 차량 케어

오리지널 실버 전기차가 깨끗한 디지털 인스펙션 스튜디오에서 휠과 하부 스캔을 받는 장면. 현실적인 장비와 재질, 딥 네이비·실버·시안 중심. 사람·진단 수치·HUD·텍스트·로고·워터마크 없음.

### 차량 라이프 여권

오리지널 화이트 전기차가 미니멀한 갤러리 안에 있고, 차량 이력·배터리·소유 기록을 상징하는 추상적 반투명 패널이 주변에 놓인 장면. 읽을 수 있는 숫자나 개인정보 없이 기록과 신뢰를 표현. 사람·텍스트·로고·워터마크 없음.

## 사용 원칙

- 생성 이미지는 기능 이해를 돕는 비주얼이며 실제 API 응답으로 오인시키지 않습니다.
- 차량 상태, 충전기 상태, 정비 기록은 이미지가 아니라 화면의 실제 데이터·출처 문구로 판단합니다.
- 이미지 위 텍스트는 충분한 대비를 확보하고 모바일에서도 차량 피사체가 잘리지 않도록 별도 크롭을 적용합니다.
