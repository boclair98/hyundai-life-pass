# HYUNDAI LIFE PASS 제품·출시 기획

기준일: 2026-09-03  
출시 목표: 다음 날 공개 가능한 모바일 웹앱(PWA) 파일럿  
제품 한 문장: 현대차 오너가 로그인 전에는 주변 충전·정비 거점을 찾고, 로그인 후에는 동의한 실차 상태와 차량 생애주기 기록을 한곳에서 관리하는 카라이프 플랫폼.

## 1. 제품 원칙

1. 실제 데이터와 예시 데이터를 섞지 않는다.
2. 성공하지 않은 예약·저장·전송을 성공했다고 알리지 않는다.
3. 차량 연결은 선택 사항이다. 충전소와 서비스 거점 탐색은 비로그인으로 제공한다.
4. 위치 권한은 사용자가 현재 위치 버튼을 누를 때만 요청하며 거부해도 기본 지역 탐색이 가능해야 한다.
5. 소비자 화면과 운영자용 CanaryDrive를 분리한다.
6. 차량·위치·인증 정보의 수집 목적, 보관, 철회 및 삭제 경로를 화면에서 확인할 수 있어야 한다.

## 2. 핵심 사용자 여정

### A. 비로그인 사용자

홈 → 충전소 또는 블루핸즈 탐색 → 상세 확인 → 전화 또는 카카오맵 길찾기 → 필요할 때만 현대 계정 연결.

### B. 현대차 오너

현대 통합계정 연결 → 현대 공식 화면에서 로그인 → 정보 제공 동의 → 차량 동기화 → 홈에서 배터리·주행 가능 거리·주행거리 확인 → 연결 해제 및 데이터 삭제.

### C. 차량 이력 사용자

연결 차량 선택 → 차량 여권 → 동기화된 이벤트와 서명 확인 → 검증 링크 공유. 공개 API로 확인할 수 없는 정비·OTA·소유권 이전은 검증 완료로 표현하지 않는다.

### D. 운영자

공개 소비자 메뉴와 분리된 CanaryDrive 읽기 전용 데모에서 릴리스 상태와 감사 이벤트 구조를 확인한다. 실제 OTA 변경 API는 운영자 토큰 없이는 사용할 수 없다.

## 3. 출시 범위

### P0 — 공개 전 반드시 완료

| 영역 | 출시 동작 | 실패·미연동 상태 |
| --- | --- | --- |
| 현대 로그인 | 공식 OAuth 이동, 콜백, 동의, 차량 동기화 | 원인과 재시도 경로 표시 |
| 게스트 홈 | 허위 차량 수치 없이 서비스 가치와 탐색 진입 제공 | 차량 연결 CTA 표시 |
| 충전 | 공공데이터 충전기 상태, 지도, 검색, 길찾기 | 마지막 정상 데이터 또는 명확한 오류 |
| 정비 | 실제 블루핸즈 검색, 위치 기준 정렬, 전화, 길찾기 | 기본 지역 결과와 재시도 |
| 내 차 | 동의한 차량만 배터리·주행거리·주행 가능 거리 표시 | 미지원 항목은 ‘제공되지 않음’ |
| 계정·개인정보 | 연결 상태, 동기화, 연결 해제와 저장 데이터 삭제 | 처리 실패 시 재시도 가능 |
| 모바일 | 360–430px, 안전 영역, 키보드, 터치 타깃, 설치형 PWA | 웹 브라우저 사용 가능 |
| 신뢰성 | 요청 ID, 타임아웃, 에러 화면, 헬스체크, 보안 헤더 | 공급자별 장애 격리 |
| 정책 | 개인정보, 이용안내, 지원·삭제 경로 | 앱 내부와 공개 URL 모두 접근 |

### P1 — 제휴 없이 출시 후 가능

- 즐겨찾는 충전소·서비스 거점
- 최근 검색과 사용자 지정 기본 지역
- 차량 동기화 시각 및 당겨서 새로고침
- 웹 푸시 또는 이메일 기반 점검 알림
- 차량 여권 PDF 내보내기
- 익명화된 오류·성능 관측 대시보드

### P2 — 현대차/CPO/블루핸즈 제휴 후에만 가능

- 충전 예약·결제·충전 시작
- 블루핸즈 가용 슬롯, 견적, 예약·변경·취소
- 디지털 키 회수와 실소유권 이전
- 실제 OTA 배포·중단·롤백
- 보증·보험·중고차 가격 연동

P2 기능은 제휴 전 공개 화면에서 완료 가능한 기능처럼 노출하지 않는다.

## 4. 정보 구조

- 홈: 연결 상태, 빠른 탐색, 연결 차량 요약 또는 명확한 빈 상태
- 충전: 검색/지도/충전소 목록/실시간 상태/길찾기
- 케어: 연결 차량 진단 또는 연결 안내/블루핸즈 검색/전화/길찾기
- 차량 여권: 연결 차량의 실제 이벤트·서명/공유
- 설정: 계정 상태/동기화/연결 해제/개인정보/이용안내/지원
- CanaryDrive: 소비자 하단 탭에서 제거하고 별도 링크로 접근

## 5. API 계약 원칙

- 모든 JSON 오류: `code`, `message`, `requestId`, `retryable` 제공.
- 모든 외부 공급자 응답: `mode`, `state`, `source`, `refreshedAt`, `message` 제공.
- 변경 요청은 인증된 세션, 소유권 검사, 중복 요청 방지를 적용한다.
- OAuth state는 일회용·10분 만료이며 토큰은 서버에서만 암호화 보관한다.
- 외부 API 타임아웃 뒤에는 마지막 정상 데이터를 `STALE`로 제공하고 실제 데이터가 없으면 `ERROR`를 반환한다.

## 6. 내일 출시 게이트

- [ ] 샘플 차량이 운영 화면에 나타나지 않는다.
- [ ] 모든 소비자 버튼이 실제 동작·외부 이동·명확한 비활성 상태 중 하나다.
- [ ] 현대 OAuth 시작과 콜백 URL이 공식 콘솔 설정과 일치한다.
- [ ] 360px, 390px, 430px에서 가로 넘침과 가려진 버튼이 없다.
- [ ] iOS Safari와 Android Chrome에서 기본 여정이 가능하다.
- [ ] 위치 권한 거부 후에도 서비스 탐색이 가능하다.
- [ ] 개인정보 페이지, 지원 URL, 데이터 삭제 진입이 로그인 없이 열린다.
- [ ] API·DB·외부 공급자 장애가 다른 탐색 기능을 모두 막지 않는다.
- [ ] 백엔드 테스트, 프론트 빌드, 브라우저 E2E가 통과한다.
- [ ] 배포 후 헬스체크와 핵심 API 스모크 테스트가 통과한다.

## 7. 출시 판정

현재 저장소는 웹 배포 구조다. 다음 날에는 설치 가능한 PWA 공개가 현실적인 목표다. App Store/Google Play 제출에는 별도 네이티브 패키지, 서명 인증서, 개발자 계정, 스토어 메타데이터와 심사가 필요하므로 공개 웹 배포와 동일한 일정으로 승인 완료를 보장할 수 없다. 네이티브 제출을 진행할 경우 이 웹앱을 Capacitor 셸로 패키징하되, 차량 로그인 콜백·외부 브라우저 복귀·위치 권한을 실기기에서 다시 검증한다.
